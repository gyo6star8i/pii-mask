# PDF 개인정보 마스킹

PDF를 Claude 같은 AI 서비스나 웹에 올리기 전에 개인정보를 가리는 도구입니다.

**바로 쓰기:** https://gyo6star8i.github.io/pii-mask/

## 특징
- **브라우저 안에서만 처리합니다.** 파일이 서버로 전송되지 않습니다.
- **자동 탐지:** 주민·외국인등록번호, 휴대전화·일반 전화번호, 이메일, 성명 칸, 계좌번호, 운전면허번호, 여권번호 (생년월일·도로명 주소는 선택)
- **직접 지정:** 이름·학교명 등 단어를 입력하면 모든 쪽에서 찾아 가립니다.
- **수동 마스킹:** 페이지 위를 드래그해 원하는 곳을 가립니다. 스캔본 PDF와 PNG·JPG 이미지에도 쓸 수 있습니다.
- **안전한 저장:** 각 쪽을 이미지로 굳혀 저장하므로, 가린 글자를 복사나 검색으로 되살릴 수 없습니다.
- **텍스트 내보내기:** 가린 글자를 ■로 바꾼 본문을 복사하거나 .txt로 저장합니다.

## 사용 순서
1. PDF를 끌어다 놓습니다.
2. 자동 탐지 결과를 확인하고, 빠진 곳은 드래그로 직접 가립니다.
3. ‘결과 미리보기’로 모든 쪽을 확인합니다.
4. 마스킹 PDF를 저장합니다.

> 자동 탐지는 보조 수단입니다. 저장하기 전에 반드시 눈으로 확인하세요.
