요즘 업무 서류 PDF를 Claude나 ChatGPT 같은 AI에 첨부해서 분석을 맡기거나, 아예 그 서류를 바탕으로 웹앱을 만들어 보는 일이 많아졌습니다. 그런데 막상 올리려고 보면 걸리는 게 있습니다. 응시원서, 경력증명서, 각종 신청서에는 주민등록번호, 전화번호, 주소, 계좌번호 같은 개인정보가 빼곡하게 들어 있으니까요.

그래서 PDF를 AI에 올리기 전에 개인정보만 골라서 가려 주는 웹 도구를 만들었습니다. 설치도, 회원가입도 필요 없고 브라우저에서 바로 쓸 수 있습니다.

👉 바로 쓰기: https://gyo6star8i.github.io/pii-mask/

첫 화면. PDF를 끌어다 놓기만 하면 됩니다.

이런 점이 좋습니다

  • 파일이 밖으로 나가지 않습니다. 모든 처리가 내 컴퓨터의 브라우저 안에서만 이루어지고, PDF가 어떤 서버에도 전송되지 않습니다.
  • 개인정보를 자동으로 찾아 줍니다. 주민·외국인등록번호, 휴대전화·일반 전화번호, 이메일, 성명 칸, 계좌번호, 운전면허번호, 여권번호를 자동으로 찾고, 도로명 주소와 생년월일은 필요할 때 켜서 쓸 수 있습니다.
  • 빠진 곳은 직접 가릴 수 있습니다. 이름이나 학교명을 입력하면 모든 쪽에서 찾아 가리고, 페이지 위를 드래그하면 원하는 곳을 직접 가릴 수 있습니다.
  • 가린 뒤에도 AI가 잘 읽습니다. 가린 자리만 [가림]으로 바뀌고 나머지 글자는 그대로 남아서, AI가 일반 PDF처럼 표와 숫자를 정확하게 읽습니다.

사용 방법

1. PDF 올리기

위 주소로 들어가 PDF 파일을 화면에 끌어다 놓거나 [파일 선택]을 누릅니다. PNG·JPG 이미지도 됩니다.

2. 자동 탐지 결과 확인하고 빠진 곳 채우기

파일을 올리면 개인정보로 보이는 곳에 분홍색 상자가 자동으로 그려집니다. 왼쪽 패널에서 항목별로 몇 건이 잡혔는지 확인할 수 있습니다.

  • 도로명 주소처럼 기본으로 꺼져 있는 항목은 체크해서 켭니다.
  • [직접 지정할 단어]에 이름을 적으면 서명란처럼 성명 칸이 아닌 곳의 이름까지 찾아 가립니다.
  • 자격번호처럼 자동으로 못 잡는 곳은 페이지 위를 드래그해서 직접 가립니다(초록색 상자).

분홍색은 자동 탐지, 초록색은 직접 그린 상자입니다. (예시 자료: 가상 인물로 만든 응시원서)

잘못 잡힌 상자는 한 번 누르면 해제되고, 직접 그린 상자는 누르면 지워집니다. 왼쪽 [찾은 항목] 목록에서도 하나씩 켜고 끌 수 있습니다.

3. 작은 글씨는 확대해서

표 안의 작은 글씨를 정확히 가려야 할 때는 위쪽의 [+] 버튼이나 Ctrl + 마우스 휠로 확대합니다(최대 300%). 확대한 상태에서도 드래그로 가리기가 그대로 됩니다.

4. 결과 미리보기로 최종 확인

[결과 미리보기]를 누르면 저장될 모습 그대로 검게 가려진 화면을 볼 수 있습니다. 자동 탐지는 보조 수단이므로, 저장하기 전에 모든 쪽을 꼭 눈으로 확인해 주세요.

5. 저장하기

왼쪽 아래 [저장]에서 방식을 고른 뒤 [마스킹 PDF 저장]을 누릅니다.

  • 글자 유지 (AI 분석용, 기본): AI에 첨부할 때 권장합니다.
  • 이미지만 (최대 보안): 글자 정보를 전혀 남기지 않고 각 쪽을 그림으로만 저장합니다.
  • 가린 자리 표기: [가림] 또는 [전화번호]처럼 항목 이름 중에서 고를 수 있습니다.

저장한 PDF는 아래처럼 보입니다.

'글자 유지' 저장은 무엇이 다른가요?

보통 PDF 위에 검은 상자만 덮으면, 화면에서는 가려져 보여도 밑에 깔린 글자는 그대로 남아 복사하거나 AI가 읽으면 다 나옵니다. 반대로 전체를 이미지로 바꾸면 안전하지만 AI가 글자를 읽기 어려워집니다.

이 도구는 두 겹으로 저장합니다. 눈에 보이는 아래층은 검게 칠한 이미지이고, 위에는 투명한 글자층을 얹는데 이 글자층에서 가린 부분만 [가림]으로 바뀌어 있습니다. 위 예시 PDF를 AI가 읽으면 이렇게 보입니다.

표 구조와 경력 날짜는 그대로 읽히고, 개인정보는 파일 어디에도 남지 않습니다. 그래서 "이 응시원서들로 경력 합산표를 만들어 줘" 같은 작업을 안심하고 맡길 수 있습니다.

PDF를 첨부하지 않고 텍스트만 쓰고 싶을 때는 [가린 텍스트 복사]를 눌러 AI 대화창에 바로 붙여넣으면 됩니다.

알아 두세요

  • 스캔한 PDF는 글자 정보가 없어서 자동 탐지가 되지 않습니다. 이때는 드래그로 직접 가려 주세요.
  • 자동 탐지는 정해진 형식(예: 000000-0000000)을 찾는 방식이라, 형식이 특이한 정보는 놓칠 수 있습니다. 저장 전 눈으로 확인하는 단계는 꼭 거쳐 주세요.
  • 인터넷 연결이 필요합니다. 프로그램을 불러올 때만 쓰고, PDF 내용은 전송하지 않습니다.

AI 활용이 늘수록 "올려도 되는 자료인가"를 먼저 따져 보는 습관이 중요해지는 것 같습니다. 학교 현장에서 서류를 다루시는 선생님들께 작은 도움이 되면 좋겠습니다. 써 보시고 불편한 점이나 추가했으면 하는 기능은 댓글로 알려 주세요.
